@topic w6-cluster :: Clustering (K-Means & Hierarchical) :: Melampaui RFM — mendeteksi segmen tersembunyi dengan K-Means dan hierarchical clustering.
@intro
- Clustering = cara go beyond RFM: mendeteksi hidden consumer segments dari data perilaku.
- Dua metode slide: K-Means (fast, partition-based, harus pilih k) dan Hierarchical clustering (tree-like grouping, cocok eksplorasi).
- K-Means: partition-based, kelompokkan data ke k cluster berdasar similarity. Cepat untuk dataset besar, tapi k harus dipilih di muka, dan paling pas untuk data numerik/kontinu.
- Tiga aplikasi K-Means di Brand Analytics: segmentasi customer by RFM scores, grouping pola sentiment review, identifikasi market niche.
- Hierarchical: bangun hierarki cluster pakai struktur pohon (dendrogram). Gak perlu pre-define jumlah cluster, dan visual dendrogram memudahkan interpretasi segmen.
- Dua tipe hierarchical: Agglomerative (bottom-up, paling umum dipakai) dan Divisive (top-down, jarang dipakai karena computational complexity tinggi).
- Aplikasi hierarchical: eksplorasi tema keluhan customer, grouping kata sentiment dari review, identifikasi sub-grup perilaku serupa.
@concept w6-kmeans :: K-Means Clustering :: Algoritma clustering berbasis partisi yang membagi data menjadi k cluster berdasarkan similarity.
@vars
Partition-based :: data dipartisi jadi k kelompok; tiap titik masuk ke cluster dengan centroid terdekat. Bukan hierarki — hasilnya rata, satu level.
Fast, large datasets :: K-Means cepat dan efisien untuk dataset besar — keunggulan utamanya dibanding hierarchical yang berat di data besar.
Requires k :: jumlah cluster harus dipilih SEBELUM jalan (pre-selecting k). Pemilihan k (elbow method, pertimbangan bisnis) adalah keputusan analyst.
Numeric data :: works best dengan data numerik dan kontinu — misal skor RFM (R, F, M masing-masing 1–5), rating, panjang ulasan.
Aplikasi 1 :: segmenting customers by RFM scores — loyal vs at-risk vs new.
Aplikasi 2 :: grouping consumers by review sentiment patterns.
Aplikasi 3 :: identifying market niches untuk targeted brand strategies.
@concept w6-hierarchical :: Hierarchical Clustering :: Clustering yang membangun hierarki kelompok dengan struktur pohon yang divisualisasikan sebagai dendrogram.
@vars
Dendrogram :: diagram pohon yang menunjukkan bagaimana cluster terbentuk dan bergabung — tinggi cabang = jarak/perbedaan antar kelompok. Potong dendrogram di ketinggian tertentu → dapat jumlah cluster.
No pre-defined k :: kebalikan K-Means: jumlah cluster gak harus ditentukan di muka — lihat dulu pengelompokan alaminya, baru potong.
Exploratory :: cocok untuk eksplorasi: dendrogram nunjukin natural groupings step by step.
Agglomerative (bottom-up) :: mulai dari tiap titik jadi cluster sendiri → merger ke grup → grup lebih besar. Paling umum dipakai. Contoh slide: tiap review jadi cluster individual → merger jadi tema "service issues", "price complaints", "positive experiences".
Divisive (top-down) :: mulai semua data dalam satu cluster → dipecah bertahap. Jarang dipakai (complexity tinggi). Contoh slide: semua customer → "satisfied" vs "unsatisfied" → "unsatisfied" dipecah lagi jadi "price too high", "poor service", "product mismatch".
@trap K-Means vs Hierarchical dibalik :: Yang perlu pre-define jumlah cluster adalah K-MEANS (k di muka). Hierarchical justru kebalikannya — tidak perlu pre-define k, dendrogramnya menunjukkan pengelompokan alami dulu. Sering tertukar di ujian.
@trap Dendrogram bukan bukti sebab :: Dendrogram menunjukkan grup kemiripan (similarity), bukan hubungan sebab-akibat antar segmen — membacanya tetap butuh interpretasi bisnis, bukan sekadar visual.

@example Dendrogram review: agglomerative bottom-up :: Slide W6 · Hierarchical Clustering
@soal
Kopi Senja mengumpulkan 8 review pendek. Pakai logika agglomerative clustering:
(a) Jelaskan langkah pembentukan cluster dari 8 review menjadi 3 tema, sesuai contoh slide.
(b) Kenapa agglomerative disebut "bottom-up" dan kenapa paling umum dipakai?
(c) Di tahap apa analyst memutuskan jumlah cluster?
@step Mulai dari titik individual :: Slide: "Start with each customer review as an individual cluster." Jadi awalnya ada 8 cluster (tiap review = 1 cluster). KENAPA: agglomerative membangun dari bawah — unit terkecil dulu.
@step Merger bertahap by similarity :: Review yang mirip merger duluan: 3 review soal pengiriman lambat → grup "service issues"; 2 review soal harga mahal → grup "price complaints"; 3 review pujian rasa → grup "positive experiences". Hasil akhir: 8 titik → 3 cluster tematik, persis pola contoh slide ("service issues, price complaints, positive experiences").
@step Baca dendrogram :: Dendrogram menunjukkan urutan merger: pasangan paling mirip bergabung di ketinggian rendah, tema berbeda bergabung di ketinggian tinggi. Analyst memotong dendrogram di ketinggian tertentu UNTUK MEMILIH jumlah cluster — keputusan JUSTRU di akhir, bukan di awal seperti K-Means.

(b) Bottom-up karena mulai dari titik individual lalu bergabung makin besar; paling umum karena cocok eksplorasi dan menunjukkan natural groupings, sementara divisive berat secara komputasi. @example Pilih metode + cluster RFM jadi segmen :: Slide W6 · K-Means + Example RFM & Clustering Results
@soal
Kopi Senja punya skor RFM 200 pelanggan (semua numerik 1–5). Tim ingin 3 segmen untuk program loyalitas bulan depan, cepat, dan bisa dijalankan ulang tiap bulan di dataset yang sama.
(a) K-Means atau hierarchical? Kenapa?
(b) Hasil clustering slide: Cluster A recent+frequent+high spend, Cluster B frequent tapi low spend, Cluster C infrequent+low spend. Interpretasikan jadi segmen awal.
(c) Kenapa clustering disebut "go beyond RFM" padahal variabelnya tetap RFM?

@step Interpretasi cluster A/B/C :: Cluster A (recent, frequent, high spenders) → Loyal Champions. Cluster B (frequent, low spend) → Value Seekers. Cluster C (infrequent, low spend) → At-Risk atau Lost Customers. Slide: "each cluster provides a starting point for persona building" — angka cluster belum persona, baru titik awal.

"sering beli tapi selalu saat promo"). Di kasus ini variabelnya RFM, tapi metodenya terbuka untuk lebih.
@answer (a) K-Means — k=3 sudah ditentukan kebutuhan bisnis, data numerik, cepat, repeatable bulanan. (b) A = Loyal Champions, B = Value Seekers, C = At-Risk/Lost — starting point untuk persona. (c) Clustering melampaui RFM karena bisa pakai ≥3 variabel apa pun (perilaku, sentiment, teks) dan mendeteksi hidden segments yang aturan RFM standar lewatkan.

@end

@topic w6-persona :: Dari Segmen ke Persona :: Menerjemahkan cluster data menjadi profil manusiawi yang bisa dipakai manajer.
@intro
- Tiga lapisan: Segmentation (what the data shows — identifikasi grup dari data RFM/perilaku), Persona (who the customer is — profil humanized per cluster), Strategic Response (how the brand should act — rencana aksi per persona).
- Persona framework 5 elemen: Demographics, Behavioral Traits, Motivations, Pain Points, Preferred Channels.
- Contoh persona dari slide: The Champion (loyal, high-value, brand advocate), The Explorer (curious, price-sensitive, suka bandingkan), The At-Risk (low frequency, disengaged, dissatisfied).
- Kenapa persona penting: menerjemahkan data jadi pemahaman manusia, memudahkan empati manajer, komunikasi terarah (bukan kampanye generik), jembatan analytics → strategi actionable.
- Manual vs automatic persona generation (Salminen et al. 2020): dua-duanya "a face to data" — beda di skala data, kecepatan, biaya, dan nuansa.
- Personas juga nunjukin posisi brand equity: Champion → Loyalty, Explorer → Awareness, At-Risk → Perceived Quality issues, Value Seeker → Brand Associations (value, price fairness).
@concept w6-seg-persona-strategy :: Segmentation vs Persona vs Strategic Response :: Tiga lapisan terjemahan dari slide: data → manusia → aksi.
@vars
Segmentation :: identifies groups of customers by data (recency, frequency, monetary, behavior) — what the data shows. Jawaban atas "apa yang kelihatan di data".
Persona :: humanized profile representing each cluster — who the customer is. Jawaban atas "siapa customernya".
Strategic Response :: tailored brand action plan per persona — how the brand should act. Jawaban atas "bagaimana brand harus bertindak".
@concept w6-persona-5 :: Persona Framework 5 Elemen :: Komponen wajib sebuah persona dari slide — dipakai untuk membangun profil lengkap tiap cluster.
@vars
Demographics :: usia, profesi, income, lokasi — kerangka "siapa" di permukaan.
Behavioral Traits :: purchase frequency, sentiment, product categories — perilaku nyata yang terbaca data.
Motivations :: apa yang mendorong loyalty atau churn — "kenapa mereka (berhenti) beli".
Pain Points :: keluhan dan unmet needs — masalah yang harus dijawab brand.
Preferred Channels :: social media, apps, offline — jalur komunikasi yang mereka sukai.
@concept w6-persona-types :: Tiga Persona Kasus + Value Seeker :: Persona contoh dari slide W6: Champion, Explorer, At-Risk — plus Value Seeker dari hasil clustering RFM.
@vars
The Champion :: loyal, high-value, brand advocate. Response slide: VIP programs, exclusive offers.
The Explorer :: curious, price-sensitive, frequent comparison shopping. Response slide: trial bundles, educational content, discounts.
The At-Risk :: low frequency, disengaged, dissatisfied. Response slide: win-back campaigns, surveys, retention offers.
The Value Seeker :: frequent tapi low spend (dari hasil clustering). Kaitan brand equity: Brand Associations (value, price fairness).
@concept w6-manual-auto :: Manual vs Automatic Persona (Salminen et al. 2020) :: Perbandingan dua cara bikin persona — dua-duanya memberi "face to data", dengan trade-off yang jelas.
@vars
Face to data :: SAMA untuk keduanya — manual maupun automatic persona sama-sama menerjemahkan data jadi wajah manusia.
Data size :: manual = small data (studi lapangan, wawancara); automatic = big data (jutaan interaksi).
Approach :: manual = qualitative; automatic = quantitative.
Speed :: manual = lambat, hitungan bulan (slow months); automatic = cepat, hitungan hari (fast days).
Responsiveness :: manual = unresponsive (susah di-update); automatic = responsive (bisa di-refresh).
Cost :: manual = expensive; automatic = affordable.
Nuance :: manual = nuanced (nuansa dalam); automatic = explicit behaviors (perilaku eksplisit yang terbaca data).
@concept w6-venn :: Analytics ∩ Personas (Venn) :: Irisan kekuatan: analytics granular/current/actionable bertemu personas simple/communicable/empathetic.
@vars
Analytics side :: granular, current, actionable — kekuatan data: detail, terkini, siap aksi.
Personas side :: simple, communicable, empathetic — kekuatan persona: mudah dipahami, mudah dikomunikasikan, membangun empati.
Irisan (best of both) :: persona berbasis data: cukup detail untuk actionable, cukup manusiawi untuk dipahami manajer — jembatan analytics → strategi.

@topic w6-strategy :: Strategic Response, Brand Equity & Severity-Urgency :: Dari persona ke rencana aksi brand: tabel strategi, kaitan ke brand equity, dan prioritisasi.
@intro
- Strategic Response Design = tabel per persona: Persona | Key Message | Channel | Offer/Value | Goal — satu baris satu rencana utuh.
- Champion: message "You are our most valued customer", channel Email/VIP events/in-app alerts, offer exclusive rewards/early access, goal retain & strengthen loyalty.
- Explorer: message "Discover more with us", channel Social media/website/promotions, offer trial bundles/discounts/guides, goal upsell & convert curiosity.
- At-Risk: message "We want you back", channel Personalized email/call center/SMS, offer re-engagement offers/surveys/support, goal re-engage & reduce churn.
- Value Seeker: message "Best value for your money", channel Social media ads/price comparison sites, offer promotions/loyalty points, goal shift perception & build trust.
- Persona juga diagnostics brand equity: Champion → Loyalty, Explorer → Awareness, At-Risk → Perceived Quality issues, Value Seeker → Associations (value, price fairness).
- Prioritisasi pakai Severity × Urgency matrix: severity = dampak ke revenue/brand, urgency = time-sensitivity. Contoh slide: At-Risk = high+high (fokus segera), Value Seeker = low+medium (monitor & nurture).
- Tugas individu W6: 20 ulasan real → preparation → RFM proxy → clustering ≥3 variabel → 3–4 segmen → persona → strategy table.
@concept w6-strategy-table :: Strategic Response Design :: Tabel rencana aksi per persona dari slide — Key Message, Channel, Offer/Value, Goal untuk tiap persona.
@vars
Key Message :: pesan inti yang persona itu perlu dengar — bukan slogan umum, tapi kalimat yang menjawab motivasinya.
Channel :: jalur delivery sesuai Preferred Channels persona (Champion: email/VIP events/in-app alerts; Explorer: social media/website/promotions; At-Risk: personalized email/call center/SMS; Value Seeker: social media ads/price comparison sites).
Offer/Value :: apa yang ditawarkan (Champion: exclusive rewards/early access; Explorer: trial bundles/discounts/guides; At-Risk: re-engagement offers/surveys/support; Value Seeker: promotions/loyalty points).
Goal :: tujuan bisnis terukur (Champion: retain & strengthen loyalty; Explorer: upsell & convert curiosity; At-Risk: re-engage & reduce churn; Value Seeker: shift perception & build trust).
@concept w6-equity-link :: Linking Personas to Brand Equity :: Persona menunjukkan di mana brand equity kuat atau lemah (slide: "Personas show where equity is strong or weak").
@vars
Champion → Brand Loyalty :: keberadaan champion yang sehat = loyalty kuat; jumlahnya (atau hilangnya) = indikator aset loyalitas.
Explorer → Brand Awareness :: explorer tahu brand tapi belum committed — kelompok ini indikator seberapa jauh awareness menjangkau.
At-Risk → Perceived Quality issues :: pelanggan yang pernah puas lalu menjauh biasanya karena kualitas yang dirasakan menurun — alarm perceived quality.
Value Seeker → Brand Associations :: value seeker nempel karena asosiasi value/harga fair; kalau asosiasinya cuma "murah", positioning bisa terkunci ke harga.
@concept w6-severity-urgency :: Severity × Urgency Matrix :: Alat prioritisasi persona: tidak semua persona butuh aksi segera — urutkan berdasar dampak × kepekaan waktu.
@vars
Severity :: dampak pada revenue/brand kalau persona itu diabaikan (mis. kehilangan champion = kehilangan revenue besar).
Urgency :: time-sensitivity — seberapa cepat jendela aksi menutup (mis. At-Risk makin lama dibiarkan makin jadi Lost).
High + High :: immediate focus — contoh slide: At-Risk customers.
Low + Medium :: monitored & nurtured — contoh slide: Value Seekers.

@trap Strategi generik lintas persona :: Satu kampanye massal untuk semua persona menghapus inti dari strategic response design — tiap persona punya key message, channel, offer, dan goal sendiri. Champion butuh exclusivity, Value Seeker butuh bukti nilai; pesan yang sama bakal meleset untuk salah satunya.
@trap Anggap semua persona sama pentingnya :: Slide: "Not all personas need immediate action." Tanpa Severity × Urgency, tim bakal kejar Champion (paling menyenangkan) padahal At-Risk (high severity + high urgency) adalah yang jendela aksinya menutup paling cepat.

@example Prioritisasi 4 persona dengan Severity × Urgency :: Slide W6 · Severity-Urgency Matrix
@soal
Kopi Senja punya 4 persona aktif dengan kondisi: Champion "Clara" (4 orang, 40% revenue, stabil), At-Risk "Andi" (12 orang, mulai menjauh, keluhan layanan naik), Explorer "Eka" (banyak, baru kenal brand dari konten viral), Value Seeker "Vino" (banyak, beli hanya saat promo). Clara (Champion): severity tinggi (40% revenue) tapi kondisi STABIL — ancamannya laten. Eka (Explorer): severity sedang — belum banyak kontribusi revenue tapi pipeline masa depan. @step Skor urgency per persona :: Andi: urgency TINGGI — tiap minggu tanpa aksi, recency memanjang → makin sulit dipulangkan (jendela menutup). KENAPA: urutan = kombinasi dua sumbu, bukan revenue semata.
