@topic w7-prep :: Text Preprocessing & Theme Coding :: Menyiapkan teks mentah jadi analizable, lalu mengelompokkan opini ke tema yang bermakna.
@intro
- Workflow W7: 1. Collect → 2. Prepare → 3. Code Themes → 4. Analyze Sentiment → 5. Map Associations → 6. Decide.
- Preprocessing 4 core tasks: Clean (hapus duplikat/spam/irrelevant), Normalize (lowercase, slang, emoji, kata berulang), Tokenize (pecah jadi term/frasa), Document (catat semua aturan cleaning secara transparan).
- Keputusan preparation menentukan validitas analisis ("Preparation decisions shape the validity of the analysis").
- Contoh slide: "Packagingnya bagusss 😍" → "packaging bagus positive-emoji"; "lama bgt kirimnya" → "lama kirim negative"; duplicate review → removed.
- Theme coding 5 tema slide: Product Quality, Service Experience, Price/Value, Identity/Lifestyle, Problem/Risk — tiap tema punya indikator + brand meaning.
- Theme coding = jembatan dari opini ke makna: tema menunjukkan apa yang sebenarnya dibicarakan konsumen.
- In-class coding exercise 4 step: clean 30–50 komentar → buat 4–6 tema & code tiap segmen → klasifikasi sentiment + validasi manual → link tema+sentiment ke brand associations & issues.
@concept w7-workflow :: Workflow Teks → Insight :: Alur 6 tahap dari slide: dari konsumen menulis sampai brand memutuskan.
@vars
1. Collect :: kumpulkan reviews, captions, comments, posts — dari platform terbuka yang relevan.
2. Prepare :: clean, normalize, tokenize, document — teks jadi analizable dan terlacak.
3. Code Themes :: kelompokkan opini ke makna (tema) — bukan cuma kata.
4. Analyze Sentiment :: polarity, emotion, intensity — per tema, bukan satu skor total.
5. Map Associations :: jaringan makna brand yang saling terhubung (nodes, edges, clusters).
6. Decide :: brand issue dan response strategy — fix, communicate, reinforce, atau reposition.
@concept w7-preprocessing :: Text Preprocessing :: Empat tugas inti menyiapkan teks — setiap keputusan di sini membentuk validitas analisis di hilir.
@vars
Clean :: hapus duplicates, spam, irrelevant posts. Kenapa: duplikat membiaskan frekuensi (satu orang bisa kelihatan seperti banyak).
Normalize :: lowercase, perbaiki slang, tangani emojis, rationalisasi kata berulang ("bagusss" → "bagus"). Kenapa: variasi ejaan membuat kata yang sama dihitung berbeda.
Tokenize :: pecah teks jadi term/frasa yang bisa dihitung. Kenapa: frekuensi dan co-occurrence butuh unit yang konsisten.
Document :: catat SETIAP cleaning rule transparan. Kenapa: analisis harus bisa direproduksi dan diaudit — aturan yang gak tercatat = temuan yang gak bisa dipercaya.
@concept w7-theme-coding :: Theme Coding 5 Tema :: Kerangka dari slide untuk menerjemahkan opini konsumen jadi makna brand.
@vars
Product Quality :: indikator: durable, effective, texture, taste, feature → brand meaning: Perceived Quality.
Service Experience :: indikator: delivery, response, complaint handling → brand meaning: Trust and satisfaction.
Price/Value :: indikator: worth it, expensive, promo, value for money → brand meaning: Value perception.
Identity/Lifestyle :: indikator: aesthetic, confident, local pride, community → brand meaning: Brand association.
Problem/Risk :: indikator: broken, fake, unsafe, misleading → brand meaning: Brand issue severity.

(4) "mahal tapi worth it positive" (Price/Value, positif dengan trade-off). (5) "promo kapan lagi question-emoji" (Price/Value, request). (6) "fake bukan original negative" (Problem/Risk — issue severity). Semua aturan dicatat (R1–R6) supaya analisis bisa direproduksi.

@topic w7-sentiment :: Sentiment by Theme & Validasi :: Klasifikasi polarity dan emosi per tema, dengan validasi manual sebelum jadi keputusan brand.
@intro
- Sentiment mengklasifikasi opini jadi positive, neutral, atau negative; analisis lanjutan mengenali EMOSI: joy, trust, anger, disappointment, pride.
- Aturan kunci: sentiment diinterpretasikan PER TEMA, bukan satu skor total — tema yang sama bisa punyi profil emosi beda.
- Emosi per tema: joy/trust biasanya nempel di Product Quality & Identity; anger/disappointment di Service & Problem/Risk; pride di Identity/Lifestyle (local pride).
- Automated model berguna tapi bisa salah baca konteks — validasi wajib sebelum keputusan brand.
- Empat risiko otomatisasi dari slide: sarcasm/irony, mixed sentiment dalam satu review, language/slang/emoji, platform bias — masing-masing punya validation action.
- Mini case skincare: 4 temuan review → theme + sentiment + brand association — lalu diskusi prioritas.
@concept w7-sentiment-def :: Sentiment & Emotion :: Klasifikasi tone opini (polarity) plus lapisan emosi yang lebih spesifik.
@vars
Positive :: tone puas/mendukung — contoh konteks W7 mini case: "Light texture and absorbs quickly" (satisfied).
Neutral :: tone informasional tanpa muatan evaluatif — bukan selalu "netral positif", bisa juga tanpa bukti brand.
Negative :: tone komplain/kecewa — contoh: "Too expensive without promo".
Emosi (lanjutan) :: joy, trust, anger, disappointment, pride — dimensi emosional yang memperkaya polarity: "kecewa" (disappointment) beda strategi dari "marah" (anger).
Per theme :: sentimen selalu dibaca per tema — polarity total menyembunyikan konflik antar aspek (produk disukang, layanan dibenci).
@concept w7-validation-risks :: Risiko Otomatisasi & Validation Action :: Empat pasangan risiko → tindakan validasi dari slide.
@vars
Sarcasm and irony :: tindakan: manual sample check dan coding notes — "great, apps-nya crash lagi" terbaca positif padahal kesal.
Mixed sentiment in one review :: tindakan: split by theme/aspect — "Works, but packaging leaks" positif di produk, negatif di kemasan.
Language/slang/emojis :: tindakan: develop local dictionary & examples — "lumayan, tapi CS lama banget" butuh kamus Indonesia.
Platform bias :: tindakan: triangulate across reviews, social posts, surveys, dan competitor data — tone tiap platform beda (W4: Instagram 68% positif vs CS chat 45% negatif).

| Finding from Reviews | Theme | Sentiment | Brand Association |
| "Light texture and absorbs quickly" | Product experience | Positive | Comfort, daily-use practicality |
| "Works, but packaging leaks" | Packaging quality | Mixed | Quality risk |
| "Too expensive without promo" | Price/value | Negative | Premium but less accessible |
| "Local brand I trust" | Identity/trust | Positive | Local pride, credibility |
@trap Satu skor sentiment untuk semua :: Slide: "Sentiment should be interpreted by theme, not only as one total score." Skor total 70% positif bisa menyembunyikan tema layanan yang 80% negatif — dan keputusan perbaikan dibuat per tema, bukan per angka rata-rata.

@topic w7-assoc :: Brand-Association Network & Social Listening Issues :: Dari teks ke peta makna brand (nodes/edges/clusters) dan keputusan isu prioritas.
@intro
- Brand-association network: nodes = kata/tema/asosiasi; edges = co-occurrence yang sering; clusters = struktur makna — cara membaca peta makna di sekitar brand.
- Brand Association Map contoh slide: Innovation (technology, creativity, modern, smart), Performance (quality, reliable, efficient, results), Trust (honest, credible, safe, consistent), Community (engagement, belonging, support, loyalty).
- Co-occurrence = seberapa sering dua kata/makna muncul BERSAMA dalam review — menunjukkan asosiasi yang terhubung di kepala konsumen.
- Social listening issue matrix: High frequency + negative → urgent fix; Low frequency + severe → management review; Positive association → amplify message.
- Langkah analitis: monitor mentions brand & kompetitor → group by theme → flag negative sentiment dengan frekuensi tinggi atau risiko strategis tinggi → translate ke response strategy.
- Empat strategi respons: fix, communicate, reinforce, reposition — terjemahan dari temuan ke aksi.
- Interpretasi jaringan tetap butuh judgment: "use interpretation, not only visuals".
@concept w7-network :: Brand-Association Network :: Peta jaringan makna brand dari data teks — dibaca lewat nodes, edges, dan clusters.
@vars
Nodes :: kata, tema, atau asosiasi — titik-titik makna (mis. "technology", "trust", "delivery").
Edges :: frequent co-occurrence — garis penghubung yang menandakan dua makna sering muncul bersama.
Clusters :: meaning structures — gugus node yang rapat = struktur makna (mis. cluster Trust: honest, credible, safe, consistent).
Interpretation :: slide: "use interpretation, not only visuals" — visual network yang indah tetap harus dibaca bisnis, bukan dipajang begitu saja.
@concept w7-bam :: Brand Association Map (Slide) :: Empat cluster asosiasi contoh dari slide: Innovation, Performance, Trust, Community — masing-masing dengan kata kunci pendukung.
@vars
Innovation :: technology, creativity, modern, smart — asosiasi brand yang inovatif.
Performance :: quality, reliable, efficient, results — asosiasi kinerja produk.
Trust :: honest, credible, safe, consistent — asosiasi kepercayaan.
Community :: engagement, belonging, support, loyalty — asosiasi komunitas dan keanggotaan.
@concept w7-listening-matrix :: Social Listening Issue Matrix :: Matriks keputusan dari slide: kombinasi frekuensi × sentimen × severity menentukan aksi.
@vars
High frequency + negative :: many complaints → action: URGENT FIX — perbaiki dulu, sinyal masalah luas yang aktif.
Low frequency + severe :: safety concern → action: MANAGEMENT REVIEW — sedikit tapi berbahaya (risiko reputasi/legal), dibahas di level manajemen.
Positive association :: love / trust / pride → action: AMPLIFY MESSAGE — kekuatan yang layak digencarkan.
